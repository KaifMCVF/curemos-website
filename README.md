# Curemos website rebuild

This build is based on the Curemos screenshots supplied in chat.

## Included
- Main homepage sections: Hero, About, 3-step consultation process
- Features section with all six feature cards
- For Doctors section (GPs + Specialists)
- Coming Soon / Launch section
- Footer
- Standalone policy/contact placeholder pages
- Responsive CSS for tablet/mobile

## Run
Open `index.html` with VS Code Live Server.

## Important asset note
The photographic assets in `assets/features`, `assets/doctors`, and `assets/launch` are cropped reference assets from the supplied screenshots. Replace them with the original high-resolution Curemos assets when available, keeping the same filenames.

Do not upload to GoDaddy until the full site is reviewed against the original site at the same browser zoom.
